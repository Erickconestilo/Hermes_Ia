# GUIA RAPIDA DE MODOS - CiudadanoInusual

## Para que sirve

Recordar rapido que pedirle a Hermes segun lo que tengas:

- una situacion que contar
- una foto
- varias fotos
- una idea de carrusel
- una duda de privacidad
- una pieza que quieres publicar

## Regla principal

No todo tiene que convertirse en contenido.

Hermes debe ayudarte a decidir:

- si hay pieza publicable;
- si es mejor guion, post o carrusel;
- que datos tapar;
- que tono usar;
- que falta para publicar.

## Modo guion

Usar cuando tienes una historia o situacion que se puede narrar en video corto.

Sirve para:

- TikTok
- Instagram Reels
- YouTube Shorts
- mini vlog
- dia en mi vida
- trabajo, comida, trayecto, estudio, hogar o humor

Prompt corto:

```text
Modo guion

Situacion:
[cuento lo que paso en bruto]
```

Hermes debe devolver:

- titulo
- hook inicial
- guion de 15-30 segundos por defecto
- guion de 30-60 segundos si necesita mas aire
- texto en pantalla
- planos sugeridos
- cierre
- frase memorable

Usar cuando:

- hay una escena con principio y final;
- hay humor, tension, cansancio o aprendizaje;
- quieres grabar voz en off o video vertical.

No usar cuando:

- solo tienes una foto simple;
- no hay historia;
- seria mejor un caption corto.

## Modo post

Usar cuando tienes una foto, video corto o momento concreto y quieres un caption.

Prompt corto:

```text
Modo post

Contexto:
[cuento que aparece en la foto o video]
```

Hermes debe devolver:

- caption corto
- caption medio
- caption mas personal
- texto alternativo
- hashtags opcionales
- riesgos de privacidad

Usar cuando:

- tienes una foto de comida;
- tienes una foto de trabajo;
- tienes una foto de trayecto;
- quieres publicar algo simple;
- quieres probar tono sin hacer video.

Regla importante:

Si es comida sencilla, no convertirlo en manifiesto. Tono ligero, cotidiano y concreto.

## Modo carrusel

Usar cuando tienes una idea que puede dividirse en 6-8 slides.

Sirve para:

- listas con humor
- cosas que nadie te cuenta
- mini guias
- errores aprendidos
- antes/despues
- reflexion de vida real
- trabajo, hogar, comida, trayecto o aprendizaje

Prompt corto:

```text
Modo carrusel

Tema o situacion:
[cuento la idea o fotos disponibles]
```

Hermes debe actuar como director creativo:

- decir si la idea tiene potencial;
- elegir el angulo;
- ordenar las imagenes;
- decir que foto usar por slide;
- indicar que falta;
- decir que recortar o tapar;
- crear slides;
- dar caption;
- dar CTA;
- avisar riesgos de privacidad.

Usar cuando:

- tienes varias fotos;
- quieres explicar algo por partes;
- quieres mezclar vida real + aprendizaje;
- quieres crear algo para Instagram o LinkedIn.

No usar cuando:

- una sola foto ya lo dice todo;
- la historia funciona mejor como guion;
- no hay una idea principal clara.

## Captura dia a contenido

Usar cuando quieres contar el dia en bruto y que Hermes decida si hay pieza.

Prompt corto:

```text
Captura dia a contenido

Hoy paso esto:
[cuento el dia como me salga]
```

Hermes debe decidir:

- si hay contenido o solo nota privada;
- mejor angulo;
- formato recomendado;
- riesgos de privacidad;
- siguiente pieza posible.

## Referencias visuales

Usar cuando tienes fotos que quieres clasificar antes de publicar.

Hermes debe decir:

- que transmite la foto;
- para que modo sirve;
- si es publicable;
- que riesgos tiene;
- que hay que tapar o recortar.

Prompt corto:

```text
Evalua esta foto como referencia visual para CiudadanoInusual.

Dime:
- que transmite;
- si sirve para guion, post o carrusel;
- riesgos de privacidad;
- si es publicable o solo referencia interna;
- que recortar o tapar.
```

## Edicion de privacidad antes de publicar

Usar antes de subir una imagen o video.

Checklist:

- tapar matriculas
- tapar caras de terceros
- tapar logos de empresa
- quitar ubicacion exacta
- quitar nombres de calle, portales o carteles
- ocultar tickets, documentos, codigos o planos
- revisar uniforme, chaleco, casco o maquinaria con marca
- confirmar consentimiento si aparece otra persona

Prompt para Hermes:

```text
Revision de privacidad para publicar

Voy a publicar esta imagen/video:
[describo o paso la imagen]

Dime:
- que debo tapar;
- que debo recortar;
- que no debo mencionar;
- si es seguro publicar;
- que caption seria prudente.
```

## Orden recomendado de trabajo

1. Capturo foto, video o situacion.
2. Uso `Modo post`, `Modo guion` o `Modo carrusel`.
3. Reviso privacidad.
4. Si pasa, preparo version final.
5. Publico o guardo como publicable.
6. Si no pasa, lo dejo como referencia interna.

## Cuando usar cada modo

| Tengo | Uso |
| --- | --- |
| una historia del dia | `Modo guion` |
| una foto suelta | `Modo post` |
| varias fotos o una lista | `Modo carrusel` |
| no se si hay contenido | `Captura dia a contenido` |
| quiero revisar una foto | `Referencias visuales` |
| voy a publicar | `Revision de privacidad` |

## Regla final

Si dudas:

1. primero privacidad;
2. luego claridad;
3. luego humor;
4. luego publicacion.

Mejor publicar algo simple y seguro que algo brillante con riesgo.
