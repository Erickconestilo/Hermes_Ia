# PROMPTS EDICION DE IMAGENES - CiudadanoInusual

## Objetivo

Tener prompts claros para revisar, tapar o preparar imagenes antes de publicar.

No sustituye una revision humana. Sirve para no olvidar privacidad, recortes y enfoque visual.

## Revision de privacidad

```text
Revision de privacidad para publicar

Voy a publicar esta imagen/video:
[describo o paso la imagen]

Dime:
- que debo tapar;
- que debo recortar;
- que no debo mencionar;
- si es seguro publicar;
- que caption seria prudente;
- si conviene usarla como post, guion o carrusel.

Prioriza:
- matriculas;
- caras de terceros;
- logos de empresa;
- ubicaciones exactas;
- tickets, documentos, codigos o planos;
- nombres de obra, cliente o empresa.
```

## Tapar datos sensibles

```text
Edita esta imagen para publicarla con seguridad.

Tapa o difumina:
- matriculas;
- caras de terceros;
- logos de empresa;
- nombres de calle o portales;
- tickets, documentos, codigos o datos de obra;
- cualquier elemento que identifique empresa, cliente o ubicacion.

Mantén la imagen natural.
No cambies el sentido de la escena.
No añadas elementos nuevos.
```

## Recorte para post

```text
Propón el mejor recorte para esta imagen como post de CiudadanoInusual.

Objetivo:
- mantener la escena clara;
- quitar datos sensibles;
- mejorar el foco visual;
- conservar tono de vida real.

Dime:
- recorte recomendado;
- que queda fuera;
- que gana la imagen;
- si sirve mejor para Instagram, LinkedIn o ambos.
```

## Recorte para carrusel

```text
Quiero usar esta imagen en un carrusel.

Dime:
- en que slide funcionaria mejor;
- si debe ser plano general, detalle o cierre;
- que recortar;
- que tapar;
- que texto podria ir encima;
- si falta otra imagen para que la secuencia funcione.
```

## Preparar imagen para LinkedIn

```text
Revisa esta imagen para LinkedIn.

Quiero que mantenga oficio y profesionalidad sin perder tono humano.

Dime:
- si es publicable;
- que debo tapar;
- que debo recortar;
- que caption profesional pero cercano encaja;
- que riesgo reputacional podria tener.
```

## Preparar imagen para Instagram

```text
Revisa esta imagen para Instagram.

Quiero que sea visual, rapida de entender y con tono CiudadanoInusual.

Dime:
- si tiene gancho visual;
- que recortar;
- que tapar;
- texto corto en pantalla;
- caption breve;
- si conviene post, story, reel o carrusel.
```

## Regla final

Si la imagen necesita demasiada explicacion o demasiado tapado, probablemente no conviene publicarla.

Mejor usarla como referencia interna.
