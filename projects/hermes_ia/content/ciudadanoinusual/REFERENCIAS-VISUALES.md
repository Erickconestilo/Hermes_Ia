# REFERENCIAS VISUALES - CiudadanoInusual

## Proposito

Registrar criterios visuales para que Hermes entienda que tipo de fotos y escenas sirven para `CiudadanoInusual` sin guardar imagenes sensibles dentro del repo.

Estas fichas no son las fotos originales. Son descripciones operativas para decidir:

- que transmite una imagen;
- que tipo de contenido puede generar;
- que riesgos de privacidad tiene;
- si conviene publicarla, recortarla, taparla o usarla solo como referencia interna.

## Regla principal

No publicar una foto solo porque exista.

Primero revisar:

- si cuenta algo real;
- si tiene una escena clara;
- si aporta oficio, humor, aprendizaje o vida cotidiana;
- si expone empresa, terceros, matriculas, ubicaciones o datos privados.

## Referencia visual 01 - Selfie de trabajo de campo bajo sol

### Que aparece

Selfie trabajando en campo con chaleco reflectante, equipo topografico cerca, sol fuerte y fondo urbano.

### Que transmite

- trabajo real
- calor
- oficio
- topografia de calle
- cansancio controlado
- vida sin postureo

### Uso posible

- `Modo post`
- post de identidad personal
- guion corto sobre calor y trabajo de campo
- post profesional suave para LinkedIn

### Riesgos

- aparece logo de empresa en el chaleco
- el fondo urbano podria ayudar a identificar la zona
- no conviene dar ubicacion exacta

### Decision

Usar como referencia interna.

Para publicar:

- recortar o tapar logo de empresa;
- evitar mencionar ubicacion exacta;
- revisar que no aparezcan datos sensibles.

### Que transmite

- usar tono general sobre oficio y escala de trabajo.

## Referencia visual 07 - Meme de mala practica topografica

### Que aparece

Captura de TikTok con una estacion colocada en una situacion de mala practica o montaje cuestionable.

### Que transmite

- humor tecnico
- mala practica como aprendizaje
- contraste entre "se puede hacer" y "se debe hacer"
- contenido viral potencial para gente del oficio

### Uso posible

- inspiracion para `Modo carrusel`
- pieza de humor tecnico sin reutilizar imagen ajena
- lista de errores o cosas que dan miedo en topografia

### Riesgos

- no es contenido propio
- tiene interfaz de TikTok y usuario visible
- puede implicar derechos de autor o exposicion de terceros

### Decision

Usar solo como referencia interna o inspiracion.

No publicar la captura directamente salvo que haya permiso o uso claro de cita/reaccion.

Mejor crear contenido propio inspirado en la idea.

## Criterio general de publicacion

Una imagen pasa como publicable si cumple al menos 3 puntos:

- cuenta una escena real;
- se entiende rapido;
- encaja con trabajo, aprendizaje, comida, trayecto, hogar o vida cotidiana;
- tiene humor, tension o reflexion;
- no expone datos sensibles;
- puede funcionar con un caption corto.

Si no cumple, usar solo como referencia interna o nota privada.
